# Pulse

Небольшой демонстрационный сайт социальной сети на React и Vite.

## Редактирование и локальный запуск

- Исходный код интерфейса находится в `src/`.
- Изображения находятся в `public/images/`.
- Установить зависимости: `npm ci`
- Запустить локально: `npm run dev`
- Проверить production-сборку: `npm run build`

Не редактируйте `dist/`: это автоматически создаваемая папка сборки, она исключена из Git. Меняйте исходники в `src/` и файлы в `public/` — они остаются в репозитории.

## Публикация

GitHub Actions проверяет pull request в `main`, а публикует сайт в GitHub Pages после обновления `main`. Адрес проекта: <https://galitskiyserega1986-jpg.github.io/pulse/>.

Путь к репозиторию на Pages учитывается автоматически; локальный запуск при этом остаётся обычным. После первого успешного запуска workflow сайт будет доступен по ссылке выше. Дальнейшие изменения попадут на сайт после push в `main`.
